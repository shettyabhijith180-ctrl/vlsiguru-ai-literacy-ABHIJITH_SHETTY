# Mission 1 — Find AI Around Me

## Examples of AI Around Me

| System / Feature | What I think it does | AI capability |
|---|---|---|
| Phone camera face detection | Detects faces in images or videos and identifies their position and facial features. | Recognition / Detection |
| Google Maps traffic and rerouting | Uses traffic information to estimate congestion and travel time and can suggest an alternative route when traffic is expected to be heavy. | Prediction / Optimisation |
| Spam call/message detection | Analyses incoming calls or messages and identifies potentially unwanted or suspicious communication. | Classification |

## Verification

I chose Google Maps for verification. Google explains that Google Maps combines historical traffic patterns with live traffic information and uses machine-learning techniques to predict future traffic conditions. These predictions are also used when determining routes, including finding lower-traffic alternatives.

Source: Google — How AI helps predict traffic and determine routes:
https://blog.google/products-and-platforms/products/maps/google-maps-101-how-ai-helps-predict-traffic-and-determine-routes/

## Could a simple rule-based program do something similar?

Yes, a simple rule-based system could perform basic actions such as:

IF road A is congested → suggest road B.

However, predicting future traffic using historical and live information is more complex. A large collection of manually written rules would be difficult to maintain and would not provide the same adaptive behaviour as a machine-learning system.

## Conclusion

I realised that AI is not just about a system appearing intelligent. The important question is what is happening underneath the system. For example, Google Maps uses machine learning to predict traffic using historical and live information, whereas some apparently intelligent features could potentially be implemented using simple predefined rules. Therefore, I should verify the underlying technology before calling a feature AI.

## Key Learning

A system that appears intelligent is not automatically an AI system. I should investigate and verify how the system actually works before making that claim.
