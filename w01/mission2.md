# Mission 2 — AI, ML, Deep Learning and Generative AI

## 1. Artificial Intelligence (AI)

Artificial Intelligence (AI) is the broad field of creating computer systems that can perform tasks that normally require some form of human intelligence. These tasks can include recognising patterns, making decisions, solving problems and understanding language.

**Example:** Google Maps uses intelligent systems to analyse traffic information, predict traffic conditions and help determine suitable routes.

---

## 2. Machine Learning (ML)

Machine Learning (ML) is an approach to AI in which a system learns patterns from data and uses those patterns to make predictions or decisions instead of relying only on explicitly written rules.

**Example:** A spam detection system can learn patterns from examples of spam and normal messages and use those patterns to classify new messages.

---

## 3. Deep Learning (DL)

Deep Learning is a subset of Machine Learning that uses neural networks with multiple layers to learn complex patterns from data. It is commonly used for tasks involving images, speech and other complex data.

**Example:** Face detection can use deep-learning models to detect faces and facial features in images or video.

---

## 4. Generative AI (GenAI)

Generative AI refers to AI systems that can generate new content based on what they have learned and the input provided by the user. The generated content can include text, images, audio, video or code.

**Example:** ChatGPT can generate text responses based on a user's prompt.

---

## 6. AI Review of My Diagram

I asked an AI assistant to review my diagram and check whether the relationship between AI, Machine Learning, Deep Learning and Generative AI was technically misleading.

The review identified one important point: showing Generative AI simply as the next level after Deep Learning could make it appear that Generative AI is always a direct subset of Deep Learning. This is not a sufficiently accurate way to describe the relationship.

I therefore modified the diagram and added a clarification. Generative AI is treated as a type or capability of AI system that generates new content, and many modern Generative AI systems are built using deep-learning models.

---

## 7. My Understanding

My understanding is that AI is the broad field, while Machine Learning is an approach in which systems learn patterns from data. Deep Learning is a subset of Machine Learning that uses multi-layer neural networks. Generative AI focuses on systems that can generate new content.

The important lesson for me is that AI, ML, Deep Learning and Generative AI are related concepts, but they should not simply be memorised as four consecutive levels.
